# Контур

Одностраничный демосайт вымышленного московского барбершопа. Цены, профили мастеров, локация и график приведены для примера.

## Запуск и публикация

Откройте `docs/index.html` в браузере. Для размещения загрузите содержимое `docs/` в нужную папку статического хостинга. Все ресурсы подключены относительными путями. Сборка, серверное приложение и внешние запросы со страницы не требуются.

## Что редактировать

| Данные | Файл и место |
| --- | --- |
| Название, заголовок вкладки, описание | `docs/index.html`, элементы `title`, `meta name="description"`, логотип, заголовок и подвал |
| Услуги и цены | `docs/index.html`, список `.price-list` внутри `#services` |
| Мастера | `docs/index.html`, секция `#team` |
| Адрес, телефон и график | `docs/index.html`, секция `#contacts` и подпись о локации на первом экране. Подставьте согласованные данные салона |
| Фотографии | `docs/*.webp`. При замене файла обновите `src`, `width`, `height` и `alt` у его тега `img`. Пропорции рамок заданы в `docs/styles.css` |
| Цвета и оформление | `docs/styles.css`, переменные в `:root` |
| Запись | Одной операцией «Заменить все» в `docs/index.html` замените `href="#booking"` на `href="https://адрес-сервиса-бронирования"`. Все три кнопки используют это назначение и работают напрямую через HTML. После перехода на реальную запись обновите демоблок `#booking` и подписи о демонстрационных данных |
| Анимация фотографий галереи | `docs/gallery.js` и правило `gallery-in` в `docs/styles.css` |

Все изображения созданы встроенным ImageGen специально для проекта. Шрифты Prata и Manrope поставляются локально, лицензии лежат в `docs/`.
